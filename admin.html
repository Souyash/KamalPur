phpMyAdmin & MySQL Database Backend

Integrated Relational Architecture for Kamalpur Abhijan Sangha

You can manage all tables directly in phpMyAdmin or through this executive admin console. Both interfaces synchronize automatically with the database.

🚀 1-Click phpMyAdmin Import Instructions:

  1. Open your local or hosted phpMyAdmin (e.g., http://localhost/phpmyadmin or XAMPP / MAMP / cPanel).
  2. Click on the Import tab in the top navigation bar of phpMyAdmin.
  3. Click Choose File and select database/schema.sql located in your project folder.
  4. Click Go at the bottom. It will automatically create the database kamalpur_db and all 5 tables (admin_users, gallery, artists, donations, members) with complete initial records.
  5. In api/db.php, adjust $db_host, $db_user, and $db_pass if your phpMyAdmin uses non-default MySQL credentials.
